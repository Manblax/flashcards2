# FlashCards2 - Обзор проекта

## 📋 Описание

FlashCards2 - современное веб-приложение для изучения материалов с помощью флэш-карточек. Frontend расположен в `frontend/` и построен на Next.js, TypeScript и DaisyUI.

## ✨ Реализованные функции

### 1. Главная страница (/)
- ✅ Отображение 6 последних модулей
- ✅ Карточки модулей с информацией о количестве терминов и авторе
- ✅ Адаптивная сетка (2 колонки на десктопе)
- ✅ Hover эффекты и плавные переходы

### 2. Страница библиотеки (/library)
- ✅ Табы для навигации (текущий таб: "Модули")
- ✅ Бесконечная прокрутка (Infinite Scroll)
- ✅ Загрузка по 20 модулей за раз
- ✅ Группировка модулей по временным периодам:
  - "НА ЭТОЙ НЕДЕЛЕ"
  - "НА ПРОШЛОЙ НЕДЕЛЕ"
  - По месяцам (например, "МАРТ 2025 Г.")
- ✅ Индикатор загрузки
- ✅ Сообщение о завершении списка

### 3. Layout компоненты
- ✅ **Sidebar** с:
  - Логотипом приложения
  - Меню навигации (Главная, Ваша библиотека)
  - Подсветка активного пункта
  - Иконки для каждого раздела
  
- ✅ **Header** с:
  - Меню-гамбургер
  - Поле поиска
  - Кнопка создания модуля (круглая с иконкой +)
  - Аватар пользователя
  - Sticky позиционирование

### 4. Дополнительные страницы
- ✅ Страница создания модуля (/create) - базовая форма
- ✅ Страница просмотра модуля (/module/[id]) - динамический роутинг

## 🔧 Технические детали

### 1. Бесконечная прокрутка (Infinite Scroll)
**Реализация:** `components/InfiniteModuleList.tsx`

```typescript
- Использует Intersection Observer API
- Загружает 20 модулей за раз
- Триггер загрузки - элемент в конце списка
- Защита от двойной загрузки (isLoading флаг)
- Определение конца списка (hasMore флаг)
```

### 2. Группировка модулей по времени
**Логика:**
```typescript
const groupModulesByPeriod = (modules: Module[]) => {
  - НА ЭТОЙ НЕДЕЛЕ (последние 7 дней)
  - НА ПРОШЛОЙ НЕДЕЛЕ (8-14 дней назад)
  - По месяцам (старше 14 дней)
}
```

### 3. Правильное склонение слов
**Функция:** `getTermWord(count: number)`
```typescript
1 термин
2-4 термина
5+ терминов
11-19 терминов (исключение)
```

### 4. Динамический роутинг
```
/module/[id] - динамическая страница для каждого модуля
Параметр id доступен через params
```

