# Быстрый старт FlashCards2

Все команды ниже выполняются из директории `frontend/`.

## Установка и запуск за 3 шага

### 1. Установите зависимости

```bash
cd frontend
npm install
```

или если используете yarn:

```bash
yarn install
```

### 2. Запустите сервер разработки

```bash
npm run dev
```

или:

```bash
yarn dev
```

### 3. Откройте в браузере

Приложение будет доступно по адресу: [http://localhost:3000](http://localhost:3000)

## Что включено

✅ **Главная страница** - `/`
  - Показывает 6 последних модулей
  - Адаптивная сетка (2 колонки на больших экранах)

✅ **Библиотека** - `/library`
  - Все модули с бесконечной прокруткой
  - Группировка по периодам (эта неделя, прошлая неделя, по месяцам)
  - Загрузка по 20 модулей

✅ **Создание модуля** - `/create`
  - Базовая форма (в разработке)

✅ **Просмотр модуля** - `/module/[id]`
  - Страница модуля (в разработке)

## Навигация

### Sidebar (слева)
- 🏠 **Главная** - главная страница с недавними модулями
- 📚 **Ваша библиотека** - полный список модулей

### Header (вверху)
- 🔍 **Поиск** - поиск по модулям (в разработке)
- ➕ **Создать** - кнопка создания нового модуля
- 👤 **Аватар** - профиль пользователя (в разработке)

## Технологии

- **Next.js 16** с App Router
- **React 19** для интерфейса
- **TypeScript** для типобезопасности
- **DaisyUI 5** для готовых компонентов
- **Tailwind CSS 4** для стилизации
- **Intersection Observer API** для бесконечной прокрутки

## Структура файлов

```text
frontend/
├── app/                    # Next.js App Router
│   ├── layout.tsx         # Корневой layout
│   ├── page.tsx           # Главная страница
│   ├── library/           # Страница библиотеки
│   ├── create/            # Страница создания
│   └── module/[id]/       # Динамическая страница модуля
├── components/            # React компоненты
│   ├── layout/           # Layout компоненты
│   ├── ModuleCard.tsx    # Карточка модуля
│   └── InfiniteModuleList.tsx
├── types/                # TypeScript типы
├── lib/                  # Утилиты и моковые данные
└── package.json          # Зависимости и скрипты
```

## Особенности UI

### Темная тема
Приложение использует кастомную темную тему с цветовой палитрой в темно-синих тонах.

### Адаптивность
- Мобильные устройства: 1 колонка
- Планшеты и десктопы: 2+ колонки
- Responsive sidebar и header

### Интерактивность
- Hover эффекты на карточках
- Плавные переходы
- Индикаторы загрузки
- Активное состояние навигации
